Give appropriate credit, link to this license, and indicate if changes were made. A clear

Credit the dataset's home page rather than the source repository. The page carries the
methodology, the denominators and the findings, and it stays correct if the code moves. This
repository is the dataset the page is built from. Copy-paste formats for every medium are in
[ATTRIBUTION.md](ATTRIBUTION.md).

When practical, also cite the census date of the values you used (the most recent census is
`2026-08-03`), so downstream readers know exactly which snapshot of the registry the figures
describe.

## Why the underlying facts are not exclusive

The raw counts (which servers exist, which entrypoints resolve, which handshakes complete) are
uncopyrightable facts, observed by probing public endpoints; only a creative selection or
arrangement attracts thin compilation copyright, never the underlying observations. We publish our
own probe results under CC BY 4.0 so the dataset stays open and reusable. See
[METHODOLOGY.md](METHODOLOGY.md) for exactly how each observation is produced.
